# Операционные системы: Курс лабораторных работ (WinAPI)

Этот репозиторий содержит цикл практических работ по изучению системного программирования в среде Windows и архитектуры операционных систем. 

---

## Цель курса
Изучение низкоуровневых механизмов ОС: управления процессами и потоками, синхронизации доступа к разделяемым ресурсам и организации межпроцессного взаимодействия через WinAPI.

---

## Содержание курса

Ниже представлен список выполненных работ с кратким описанием изученных технологий:

### 1. [Создание и управление процессами](./Lab1)
*   **Тема:** Основы жизненного цикла процессов.
*   **Ключевые слова:** `CreateProcess`, `WaitForSingleObject`, передача аргументов командной строки.
*   **Задача:** Система из трёх процессов (Main, Creator, Reporter) для обработки бинарных данных.

### 2. [Многопоточность и общая память](./Lab2)
*   **Тема:** Параллельные вычисления внутри одного процесса.
*   **Ключевые слова:** `CreateThread`, `Sleep`, манипуляция общим массивом данных.
*   **Задача:** Создание потоков для вычисления характеристик массива (min, max, average) в режиме реального времени.

### 3. [Синхронизация потоков](./Lab3)
*   **Тема:** Решение проблем Race Condition и Deadlock.
*   **Ключевые слова:** `CRITICAL_SECTION`, `Events` (Manual/Auto Reset).
*   **Задача:** Моделирование конкуренции потоков-маркеров за доступ к ячейкам памяти.

### 4. [Межпроцессное взаимодействие (IPC)](./Lab4)
*   **Тема:** Передача данных через общие ресурсы.
*   **Ключевые слова:** `Mutex`, `Semaphore`, кольцевая очередь (FIFO) в бинарном файле.
*   **Задача:** Синхронизация независимых процессов Receiver и Sender по модели «Производитель-Потребитель».

### 5. [Архитектура Клиент-Сервер](./Lab5)
*   **Тема:** Обмен данными по именованным каналам (Named Pipes).
*   **Ключевые слова:** `CreateNamedPipe`, `ConnectNamedPipe`, блокировка записей.
*   **Задача:** Построение системы удаленного доступа к базе данных с поддержкой параллельного чтения и эксклюзивной записи.
