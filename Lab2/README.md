# Лабораторная работа №2: Создание и управление потоками (WinAPI)

## Обзор проекта
Данный проект демонстрирует принципы многопоточного программирования в операционной системе Windows. Программа создает три параллельных потока (`main`, `min_max`, `average`), которые работают с общим массивом данных.

**Основная цель:** освоение механизмов создания потоков, передачи параметров в потоковую функцию и синхронизации работы потоков через ожидание их завершения.

---

## Описание потоков

### 1. Поток main (Главный поток)
*   Выполняет инициализацию массива (размер и элементы вводятся пользователем).
*   Запускает дочерние потоки `min_max` и `average`.
*   Использует механизм **синхронизации**, чтобы дождаться результатов вычислений.
*   Производит модификацию массива: заменяет экстремальные значения (min и max) на вычисленное среднее арифметическое.

### 2. Поток min_max
*   **Задача:** Поиск минимального и максимального элементов в массиве.
*   **Особенность реализации:** Для имитации длительной работы потока используется функция `Sleep(7)` после каждой операции сравнения.
*   **Результат:** Выводит найденные значения в консоль.

### 3. Поток average
*   **Задача:** Вычисление среднего арифметического значения элементов массива.
*   **Особенность реализации:** Использует функцию `Sleep(12)` после каждой операции суммирования.
*   **Результат:** Выводит результат вычислений в консоль.

---

## Технические подробности реализации

*   **Создание потоков:** Использование системного вызова `CreateThread` для запуска параллельных вычислений.
*   **Синхронизация:** Применение функции `WaitForSingleObject` с параметром `INFINITE`. Главный поток приостанавливает свою работу до тех пор, пока `min_max` и `average` не завершат выполнение.
*   **Имитация задержек:** Использование функции `Sleep` для демонстрации асинхронной природы потоков и визуализации их работы в реальном времени.

## Инструкция по запуску
1. Скомпилируйте исходный код с помощью компилятора C++ (например, в Visual Studio).
2. Запустите полученный исполняемый файл.
3. Введите размерность массива и его элементы.
4. Наблюдайте за выводом потоков `min_max` и `average`.
5. Изучите итоговое состояние массива после замены элементов в главном потоке.
