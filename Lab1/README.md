# Лабораторная работа №1: Создание процессов (WinAPI)

## Обзор проекта
Данный проект демонстрирует базовые принципы управления процессами в операционной системе Windows с использованием **WinAPI**. Система состоит из основной программы-координатора (**Main**) и двух вспомогательных утилит (**Creator** и **Reporter**).

**Основная цель:** освоение механизмов создания независимых процессов, передачи параметров через командную строку и синхронизации их выполнения.

---

## Компоненты системы

### 1. Программа Main (Координатор)
Является «диспетчером» всей системы. 
* Запрашивает данные у пользователя.
* Управляет жизненным циклом дочерних процессов.
* Синхронизирует этапы записи и чтения данных.

### 2. Утилита Creator (Создание данных)
Автономная консольная программа для генерации бинарного файла.
* **Входные данные:** имя файла и количество записей.
* **Функционал:** записывает структуры `employee` в бинарном виде.

### 3. Утилита Reporter (Генерация отчета)
Программа для обработки данных и создания текстового документа.
* **Входные данные:** бинарный файл, имя отчета и почасовая ставка.
* **Функционал:** рассчитывает зарплату и формирует таблицу в `.txt` файле.

---

## Технические особенности реализации

*   **Синхронизация процессов:** Использование системного вызова `WaitForSingleObject` с флагом `INFINITE` для ожидания завершения дочерних процессов.
*   **Inter-Process Communication (IPC):** Передача параметров через аргументы командной строки (`lpCommandLine` в `CreateProcess`).
*   **Работа с данными:** Использование бинарного ввода-вывода для сохранения целостности структур данных.

## Структура данных
```cpp
struct employee {
    int num;         // Идентификационный номер
    char name[10];   // Имя
    double hours;    // Отработанные часы
};
```
---

## Инструкция по запуску
1. Скомпилируйте файлы `Main.cpp`, `Creator.cpp` и `Reporter.cpp` (рекомендуется использовать Visual Studio или компилятор `cl`).
2. Убедитесь, что все три созданных `.exe` файла находятся в одной папке.
3. Запустите основной файл `Main.exe`.
4. Следуйте подсказкам в консоли для ввода данных.
